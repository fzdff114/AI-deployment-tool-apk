# 功能与使用说明

## 云端 API
在首次启动页选择 OpenAI、DeepSeek、OpenRouter 或自定义兼容接口，填入 API 地址、模型 ID 与 API Key。默认请求路径为 `/chat/completions`，使用 OpenAI Chat Completions 兼容格式和 SSE 流式输出。

- 单次回复 Token 上限可以在「设置 → 对话额度」调整。
- 会话累计额度可以设定为 0（不限额）或固定上限。
- 推理强度参数默认不发送；启用后会把 `reasoning_effort` 发送给支持它的 API。
- 额度统计为客户端估算值，不等同于服务商账单统计。

## 本地 GGUF
在「模型 → GGUF 模型库」批量导入一个或多个 .gguf 文件。当前 Android 版通过 JNI 在应用进程内调用 llama.cpp CPU 后端，不依赖 Termux、Python、HTTP 本地服务器或其他应用；模型文件不会打包进 APK。

模型库会扫描应用私有模型目录、检查 GGUF 文件头、为重名文件自动改名，并展示文件大小和根据文件名推测的量化标签。可设为当前模型、加载、卸载释放内存、删除（带二次确认）以及刷新模型列表。

可配置上下文长度和 CPU 线程数；采样项包括 Temperature、Top-P、Top-K、重复惩罚。支持自定义系统提示词和自动/通用、ChatML、Llama 3、Phi、Alpaca 聊天模板。设置保存在本机，采样配置会传入 llama.cpp 原生 sampler，而不只是界面显示。

当前只打包 arm64-v8a，使用 CPU 推理，尚未启用 Vulkan/GPU 层卸载。mmproj GGUF 可与主模型一起导入和保留，但当前 JNI 尚未接入 llama.cpp mtmd/视觉解码，因此图片理解还不可用。音频推理和扩散图像生成也不属于当前 GGUF 本地引擎功能。

设备可用内存、GGUF 架构、量化类型和上下文大小都会影响能否加载。建议先从小体积 Q4 量化模型及 2048/4096 上下文开始。

## 工作区
输入目标文件名与开发需求，云端 API 或已加载的本地模型会生成文件正文。生成结果可以复制或通过 Android 系统文件选择器导出。

## 配色
- 白蓝：白色底、蓝色主按钮（默认）
- 米白：暖米白背景和棕色强调色
- 黑白：深黑背景、白色主按钮

## 兼容性
最低 Android 9（API 28），为 ARM64 手机构建。网络 API 需要连接互联网；本地 GGUF 推理无需联网。仅在用户主动选择文件时访问对应文档，不请求整个共享存储权限。
