# 功能与使用说明

## 云端 API
在首次启动页选择 OpenAI、DeepSeek、OpenRouter 或自定义兼容接口，填入 API 地址、模型 ID 与 API Key。默认请求路径为 `/chat/completions`，使用 OpenAI Chat Completions 兼容格式和 SSE 流式输出。

- 单次回复 Token 上限可以在「设置 → 对话额度」调整。
- 会话累计额度可以设定为 0（不限额）或固定上限。
- 推理强度参数默认不发送；启用后会把 `reasoning_effort` 发送给支持它的 API。
- 额度统计为客户端估算值，不等同于服务商账单统计。

## 本地 GGUF
进入「模型」导入 GGUF，再点击加载。当前 Android 版本通过 JNI 在应用进程中调用 llama.cpp CPU 后端，不依赖终端、Python、HTTP 本地服务器或另外的应用。模型文件不会内置在 APK 里。

首版只打包 arm64-v8a ABI。建议从小体积 Q4 模型开始，设备可用内存、模型架构和上下文大小都会影响能否加载。暂未加入 Vulkan/GPU 加速。

## 工作区
输入目标文件名与开发需求，云端 API 或已加载的本地模型会生成文件正文。生成结果可以复制或通过 Android 系统文件选择器导出。

## 配色
- 白蓝：白色底、蓝色主按钮（默认）
- 米白：暖米白背景和棕色强调色
- 黑白：深黑背景、白色主按钮

## 兼容性
最低 Android 9（API 28），为 ARM64 手机构建。网络 API 需要连接互联网；本地 GGUF 推理无需联网。仅在用户主动选择文件时访问对应文档，不请求整个共享存储权限。
